# mcadams-core

Núcleo de procesamiento para anonimización de voz con el coeficiente de McAdams estocástico (`mcadams_core`): análisis LPC y transformación por trama, anonimización incremental y de audios completos, y coeficiente por sesión. Entornos, pruebas y uso: ver el [README raíz](../../README.md).
